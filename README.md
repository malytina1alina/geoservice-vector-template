# GeoMarketing Analysis – геоинформационный сервис оценки потенциала размещения объектов

Сервис по объектам OpenStreetMap и данным о населении GHS-POP оценивает, сколько объектов темы можно ожидать в каждой ячейке гексагональной сетки H3 выбранной области, и показывает места, где их меньше ожидаемого (места-кандидаты).

Два режима:

* **своя модель** – обученная модель из `models/` применяется к выбранной области. Сервис предупреждает о ячейках, признаки которых выходят за диапазон городов обучения.
* **обучение на лету** – модель обучается по выбранной области и тегам OpenStreetMap для объектов темы и дополнительных факторов. Ожидаемое число – прогноз вне обучения по пространственным блокам.

Город выбирается из справочника 41 города или вводится названием. Предел площади при поиске города вне справочника задаётся параметром `MAX_AREA_KM2` (по умолчанию 1500 км²). В режиме **«Полигон»** можно нарисовать полигон, квадрат или круг, либо загрузить границы из GeoJSON, GeoPackage или ZIP с SHP. Можно применить все полигоны или выбрать один. В расчёт входят целые ячейки H3, пересекающие контур. Для признаков окружения используются также соседние ячейки.

Объекты OpenStreetMap загружаются через выбранное быстрое зеркало Overpass API с переходом на запасные при задержке или ошибке. Результаты доступны в интерактивной карте, отчёте HTML, GeoPackage и GeoJSON.

## Устройство

| Файл или папка | Назначение |
|---|---|
| `main.py` | страница Streamlit – главный файл приложения: область интереса, режим, карта, таблицы, файлы и отчёт HTML |
| `extensions.py` | собственная функция: дополнительный расчёт, результат которого сервис показывает таблицей, выводом и слоем карты |
| `client/` | клиентская часть: `interface.py` – оформление страницы и область интереса (границы из файлов GeoJSON, GeoPackage, ZIP с SHP и нарисованные фигуры); `maps_and_report.py` – карты folium и отчёт HTML; `presets.json` – готовые наборы тегов OpenStreetMap |
| `server/` | серверная часть: `api.py` – FastAPI (`GET /analyze?city=…`, `POST /analyze` для своей области, `POST /train`, `/place?city=…`, `/cities`, `/health`); `analysis.py` – население GHS-POP, своя модель и обучение на лету, адреса мест-кандидатов; `osm_features.py` – справочник 41 города, граница города, объекты OpenStreetMap и признаки ячеек H3; `overpass_mirrors.py` – выбор самого быстрого зеркала Overpass API и переход на запасные |
| `models/vector_model/` | модель сервиса: `model.joblib` и карточка `card.json` |

Для расчёта по своим границам запрос `POST /analyze` или `POST /train` передаёт название в поле `city` и геометрию GeoJSON `Polygon` или `MultiPolygon` в поле `geometry`. Координаты задаются в WGS 84.

Всё, что зависит от темы модели (теги объектов, дополнительные факторы, признаки, города обучения, диапазоны признаков), сервис берёт из `card.json`. Чтобы подключить другую модель, удалите папку `models/vector_model/` и распакуйте в корень репозитория архив модели `пакет_для_сервиса.zip`: на её месте появится папка новой модели. Затем при необходимости измените собственную функцию в `extensions.py`.

## Развёртывание на Streamlit Community Cloud

Сервис разворачивается одним приложением: страница Streamlit и серверная часть FastAPI работают в одном процессе, страница обращается к серверной части без сети.

1. Сделайте форк репозитория (кнопка **Fork**).
2. В [Streamlit Community Cloud](https://share.streamlit.io) создайте приложение из своего форка: ветка `main`, главный файл (**Main file path**) `main.py`, в **Advanced settings** – Python 3.12.
3. В поле **Secrets** вставьте ключ сервисного аккаунта Google Earth Engine – полное содержимое JSON-файла между тройными кавычками:

   ```toml
   EE_SERVICE_ACCOUNT = '''
   ВСТАВЬТЕ СЮДА ПОЛНОЕ СОДЕРЖИМОЕ JSON-ФАЙЛА КЛЮЧА
   '''
   ```

4. Нажмите **Deploy**. Библиотеки устанавливаются из `requirements.txt`, первый запуск занимает несколько минут.

Серверную часть можно развернуть и отдельно (например, в FastAPI Cloud): приложение – `server.api:app`, ключ и проект задаются переменными окружения `EE_SERVICE_ACCOUNT` и `EE_PROJECT`. Тогда странице задаётся секрет `API_URL` – адрес серверной части.

## Секреты

* `EE_SERVICE_ACCOUNT` – содержимое JSON-ключа сервисного аккаунта Google Earth Engine; `EE_PROJECT` – идентификатор проекта, если он отличается от проекта ключа;
* `API_URL` – адрес отдельно развёрнутой серверной части; без него серверная часть работает внутри приложения.

Сервисному аккаунту в проекте Google Cloud нужны роли «Earth Engine Resource Admin» и «Service Usage Consumer», а сам проект должен быть зарегистрирован для работы с Earth Engine. Ключ хранится только в секретах платформы развёртывания и никогда не записывается в репозиторий.

## Локальный запуск

```bash
pip install -r requirements.txt
streamlit run main.py
```

Страница сама запускает серверную часть внутри себя. Чтобы проверить серверную часть отдельно (страница `/docs`), запустите `uvicorn server.api:app --port 8100` и задайте странице переменную окружения `API_URL=http://localhost:8100`.
